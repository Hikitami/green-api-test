# Демо

Демо позволяет проверить чат без аккаунта GREEN-API. Оно доступно при разработке и в production-сборке.

`fixtures.ts` содержит вымышленные контакты и историю в формате уведомлений GREEN-API. `mock-api.ts` реализует интерфейс `GreenApi` в памяти. `DemoPanel.tsx` подключает этот клиент к сессии и предоставляет кнопки для проверки входящего сообщения и ошибки отправки.

Отправленный текст получает статусы `delivered` и `read`, затем в очередь добавляется один из заранее заданных ответов. Уведомление остаётся в очереди до подтверждения. Обычные features отправки и получения работают без изменений.

Кнопка «Ошибка следующей отправки» один раз имитирует HTTP 429. Для проверки отсутствующего пользователя можно создать чат с `@not_found`. Остальные корректные номера и имена в демо считаются существующими.

Демо не создаёт HTTP-клиент, не использует токены и не обращается к GREEN-API. При выходе сессия и переписка очищаются. Переход к обычному режиму выполняется через страницу подключения.

Браузерный тест `e2e/demo.spec.ts` проверяет работу демо с заблокированными запросами к GREEN-API.
